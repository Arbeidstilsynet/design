There is built-in accessibility in the [Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API) for open and closed state, as well as keyboard navigation.

### Keyboard navigation

- <kbd>Enter</kbd> or <kbd>Space</kbd> opens or closes the menu
- <kbd>Enter</kbd> or <kbd>Space</kbd> selects the highlighted item
- <kbd>Esc</kbd> closes the menu

### Arrow key navigation

You can combine Dropdown with [focusgroup](https://designsystemet.no/en/components/utilities/focusgroup) to enable arrow navigation between items.
