## Usage

Details is a native `<details>` element.
We polyfill a bug in Firefox when used with Android Talkback screen reader to announce state and role correctly.

```html
<!-- without frame -->
<details class="ds-details">
  <summary>Details heading text</summary>
  <div>Details content</div>
</details>

<!-- with frame -->
<div class="ds-card">
  <details class="ds-details">
    <summary>Details heading text</summary>
    <div>Details content</div>
  </details>
</div>
```

## CSS variables and data attributes

Sizes are controlled with [data-size](https://designsystemet.no/en/fundamentals/code/sizes) and colors with [data-color](https://designsystemet.no/en/fundamentals/code/colors).
The component will inherit from the closest parent where these are set.

## React

```tsx
/* Without frame */
import { Details } from "@arbeidstilsynet/design-react";

<Details>
  <Details.Summary>Details heading text</Details.Summary>
  <Details.Content>Details content</Details.Content>
</Details>;

/* With frame */

import { Details, Card } from "@arbeidstilsynet/design-react";

<Card>
  <Details>
    <Details.Summary>Details heading text</Details.Summary>
    <Details.Content>Details content</Details.Content>
  </Details>
</Card>;
```
