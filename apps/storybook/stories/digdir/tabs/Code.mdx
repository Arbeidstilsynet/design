## Usage

We extend [u-tabs (u-elements.github.io)](https://u-elements.github.io/u-elements/elements/u-tabs), which is a web component that implements tabs.
Add the class name `ds-tabs` on the `<ds-tabs>` element to get Designsystemet styling.

We recommend using `<ds-tabs>`, and not building your own tabs from scratch, to ensure good accessibility and functionality.

## CSS variables and data attributes

Sizes are controlled with [data-size](https://designsystemet.no/en/fundamentals/code/sizes) and colors with [data-color](https://designsystemet.no/en/fundamentals/code/colors). The component will inherit from the closest parent where these are set.

## React

```tsx
import { Tabs } from "@arbeidstilsynet/design-react";

<Tabs defaultValue="tab1">
  <Tabs.List>
    <Tabs.Tab value="tab1">Tab 1</Tabs.Tab>
    <Tabs.Tab value="tab2">Tab 2</Tabs.Tab>
  </Tabs.List>
  <Tabs.Panel value="tab1">Content 1</Tabs.Panel>
  <Tabs.Panel value="tab2">Content 2</Tabs.Panel>
</Tabs>;
```
