## Usage

Append the class name `ds-input` to `<select>`.

If you want `readonly` on a select, you must stop `onKeyDown` and `onMouseDown` yourself to prevent changing the state.

## CSS variables and data attributes

Sizes are controlled with [data-size](https://designsystemet.no/en/fundamentals/code/sizes) and colors with [data-color](https://designsystemet.no/en/fundamentals/code/colors). The component will inherit from the closest parent where these are set.

The `ds-input` class can also be used to style [input](?path=/docs/designsystemet-no-input--overview) and [textarea](?path=/docs/designsystemet-no-textarea--overview).

## Example

### Grouping

You can use `<optgroup>` to group options into categories, making long lists more manageable and easier to navigate.

<Canvas of={SelectStories.WithOptgroup} />

### ReadOnly

`<select>` is always `:read-only`, and does not support this in the same way as input types you can type into.

If you set `aria-readonly` on a `<select>`, we ensure that it behaves as if it has read-only access, by preventing `onKeyDown` and `onMouseDown`.

The user will still be able to focus on the element.
