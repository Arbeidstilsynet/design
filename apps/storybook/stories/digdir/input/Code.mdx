## Usage

The class `ds-input` is used on most form controls, such as `<input>`, `<textarea>`, and `<select>`.

```html
<input class="ds-input" />
<textarea class="ds-input" />
<select class="ds-input" />
```

For a valid form element, we recommend using `<ds-field>` together with a `<label>`.

```html
<ds-field class="ds-field">
  <label class="ds-label">Checkbox</label>
  <input class="ds-input" />
</ds-field>
```

## CSS variables and data attributes

Sizes are controlled with [data-size](https://designsystemet.no/en/fundamentals/code/sizes) and colors with [data-color](https://designsystemet.no/en/fundamentals/code/colors).
The component will inherit from the closest parent where these are set.

## Validation and error state

By design, the Input does not automatically receive error styling based on the browser's built-in `:invalid` state.
To give you control over when the error state is displayed, we recommend instead showing and hiding an associated [Validation message](?path=/docs/designsystemet-no-typography-validationmessage--overview) with the `hidden` attribute.
When the [Validation message](?path=/docs/designsystemet-no-typography-validationmessage--overview) and the Input are placed within the same [Field](?path=/docs/designsystemet-no-field--overview), the Input automatically receives `aria-invalid="true"` when necessary.
