## Usage

The class name `ds-divider` is applied directly to the `<hr>` element.
Apply `aria-hidden="true"` to avoid noise in screen readers.

## CSS variables and data attributes

Sizes are controlled with [data-size](https://designsystemet.no/en/fundamentals/code/sizes) and colors with [data-color](https://designsystemet.no/en/fundamentals/code/colors). The component will inherit from the closest parent where these are set.
