## Usage

You use either `<ul>` or `<ol>` with the class name `ds-list`.
`<li>` is used for each list item, and does not need a class name.

## CSS variables and data attributes

Sizes are controlled with [data-size](https://designsystemet.no/en/fundamentals/code/sizes). The component will inherit the closest parent where this is set.
