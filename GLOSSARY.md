# Gnist

Gnist is Arbeidstilsynet's design system, built on top of Designsystemet from
Digdir.

## Documentation

**Upstream docs**:
Digdir's component documentation as published on designsystemet.no.
_Avoid_: Digdir MDX, www docs, the new docs

**Gnist docs**:
Documentation written and owned by the Gnist team.
_Avoid_: Our docs, local docs

**Adapted copy**:
A Gnist file derived from upstream docs or stories that records which upstream
file and Designsystemet version it came from.
_Avoid_: Vendored file, mirror, fork

**Upstream sync**:
Bringing every adapted copy up to date with the installed Designsystemet
version.
_Avoid_: Docs sync, migration
